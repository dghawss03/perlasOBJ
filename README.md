# Perlas Relaunch – Frontend-Prototyp V1

Responsiver Startseiten-Prototyp für die Neupositionierung von Perlas als professioneller Objekt- und Facility-Dienstleister.

Version 2 ergänzt die kräftige Perlas-Blau-Farbwelt, größere Corporate-Typografie, einen barrierearm bedienbaren Vierfach-Hero-Slider und einen austauschbaren Team-Bereich.

## Lokal starten

```bash
npm install
npm run dev
```

Produktions-Build: `npm run build`

## Status der Inhalte

- Kennzahlen, Kundenstimme, Blogdaten und Cases sind Demo-Inhalte.
- Die Referenz „Bundesanstalt für Immobilienaufgaben“ benötigt vor Veröffentlichung eine Freigabe.
- Qualitäts-/Zertifikatsfelder sind neutrale Platzhalter und treffen keine Zertifizierungsaussage.
- Wortmarke und die drei KI-erstellten Fotomotive sind temporäre Relaunch-Konzepte.
